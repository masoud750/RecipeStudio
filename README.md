Project Overview
This project demonstrates how to integrate a SQLite database into a WPF application using Entity Framework Core.
It includes:

Entity Framework Core with SQLite  
Configuration, context setup, and database connection.

Automatic database creation and migrations at application startup  
The application ensures the database exists and applies pending migrations.

A simple repository pattern for CRUD operations  
Clean separation of data access logic.

Dependency Injection in a WPF application  
Using Microsoft.Extensions.DependencyInjection to register services, repositories, and view models.

Basic MVVM structure  
ViewModels, Views, and a clean separation of concerns.

This repository serves as a minimal, clean example for developers who want to learn how to integrate EF Core into a WPF desktop application.
